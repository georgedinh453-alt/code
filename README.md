# BlockVerse

A small Roblox-inspired sandbox prototype built with plain HTML, CSS, and JavaScript.

## How to run

Open the project in a browser, or serve it locally:

```bash
cd /workspaces/code
python3 -m http.server 8000
```

Then visit http://localhost:8000

## Controls

- A / D or arrow keys: move
- Space: jump
- B: toggle build mode
- Mouse click: place a block in build mode
- R: reset player
